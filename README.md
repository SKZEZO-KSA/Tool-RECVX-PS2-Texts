# Tool RECVX PS2 Texts

Text editing tool for **Resident Evil Code: Veronica X – PlayStation 2**.

Developed by **SKZEZO**

## Features

- Open and scan PS2 ISO files.
- Extract and edit game text.
- ELF text support.
- RDX text support.
- SYSMES text support.
- RDX PRS decompression and recompression.
- AFS archive repacking.
- Direct saving back to the same ISO.
- Automatic handling of larger edited RDX files.
- Repack progress bar.
- Multiple game language support.
- Custom TBL support.
- Arabic text support.
- Arabic character shaping and game-ready text order.
- Text preview before saving.
- Multi-line text preview.
- Automatic preview fitting for long text.
- Font texture preview.
- Character spacing and font advance editing.
- CSV import and export.
- Search across game text.
- Automatic save support.
- Drag and drop support.

## Supported Text Sources

- ELF
- RDX
- SYSMES
- AFS

## Supported Languages

- French

- Arabic
